## How To Regenerate

```bash
python src/viz/plot_metrics.py
```

If labels or aggregate metrics change, update `src/viz/plot_metrics.py` and regenerate the PNGs. Do not silently keep old chart values after changing `data/ground_truth/combined_labels.json`.

## Interpretation Rules

- Stage 3 “0% FP” means no false positives among reported findings on the final measured corpus. It is not a universal FP guarantee.
- Obfuscation charts must separate hand-crafted samples from real-world plausibility checks.
- Origin breakdown matters because PleOS-customized, external vulnerable corpus, and AOSP-derived components behave differently.
- Runtime/local evidence charts must not be published unless redaction review is complete.
